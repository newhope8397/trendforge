# TrendForge 🚀

**TrendForge** is a lightweight, mobile-first web app that combines 2-minute micro-learning cards, an AI short-video script generator, and actionable micro-gigs.

## 🌟 Key Features

1. **2-Min Decks:** Bite-sized, swipeable cards for study formulas, book summaries, and quick reads.
2. **Script AI:** Generates 15-second viral video scripts with 3 hooks and teleprompter-style bodies.
3. **Micro-Gigs:** Curated 15-minute digital tasks designed to help users earn using free web tools.

## 🛠️ Built With

* HTML5
* Tailwind CSS
* Vanilla JavaScript
* Hosted via GitHub Pages

## 🚀 How to Run Locally

Simply clone the repository and open `index.html` in any web browser—no installation or build steps required!
